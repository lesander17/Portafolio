## Desarrollo

Requiere Python 3. No necesita instalar dependencias ni compilar.

```sh
cd /workspace/Portafolio
npm run dev
```

También puede ejecutarse con `python3 -m http.server 3000 --bind 0.0.0.0`.

Se conservan el HTML, CSS, JavaScript, imágenes, certificados y enlaces originales.
Los cambios de presentación y posicionamiento profesional quedan para una próxima etapa.

## Limitaciones originales

- El formulario usa `email.php`: el servidor estático no ejecuta PHP ni envía correos. El destinatario del archivo es el de la plantilla original. No habilitarlo en producción sin configurar y validar una integración de contacto propia.
- Las fuentes de Adobe Typekit requieren conexión externa; hay fuentes de respaldo.
- Los informes de Power BI y Looker Studio son enlaces externos y su disponibilidad depende de sus propietarios.
